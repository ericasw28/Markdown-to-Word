# Mermaid Stuff

## Entity Relationship Diagram
Basics of Relation design
**Note** : Relationships types disappear in read mode.
	v--> --> - - > --> <-- 
	| | - - o { 
```mermaid
erDiagram
    CUSTOMER ||--o{ ORDER : places
    ORDER ||--|{ LINE-ITEM : contains
    CUSTOMER }|..|{ DELIVERY-ADDRESS : uses
```

## Flowchart

This code 
	```mermaid 
	graph LR 
	A{Biology} --> Chemistry
	A -- nope --> Geology
	Chemistry --> Physics 
	```
will render this chart

```mermaid 
graph LR 
A{Biology} --> Chemistry
A -- nope --> Geology
Chemistry --> Physics 
```

## Sequence Diagram
This code 
	```mermaid 
	sequenceDiagram 
	Alice->>+John: Hello John, how are you? 
	Alice->>+John: John, can you hear me? 
	John-->>-Alice: Hi Alice, I can hear you! 
	John-->>-Alice: I feel great! 
	```
Will render this chart
```mermaid 
sequenceDiagram 
Alice->>+John: Hello John, how are you? 
Alice->>+John: John, can you hear me? 
John-->>-Alice: Hi Alice, I can hear you! 
John-->>-Alice: I feel great! 
```

## Latex Math
This code with double $
	\begin{vmatrix} 
	a & b\\ c & d \
	end{vmatrix}=ad-bc
Will generate:
$$ \begin{vmatrix} 
a & b\\ c & d 
\end{vmatrix}
=ad-bc $$
This is an inline math expression $e^{2i\pi} = 1$. It is used with a single $, exemples : $x = 3$ , $a^2 + b^2 = a^2 + ab + b^2$
$$\int_{a}^b\int_{c}^d f(x,y)dxdy$$
